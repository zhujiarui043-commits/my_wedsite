# Social icons

SVG assets from [Simple Icons](https://github.com/simple-icons/simple-icons/tree/develop/icons).
The original license is preserved in `LICENSE.md`.

- `wechat.svg`: WeChat.
- `tiktok.svg`: musical-note logo used for Douyin.
- `gmail.svg`: Gmail.
- `github.svg`: GitHub.
- `xiaohongshu.svg`: Xiaohongshu brand wordmark.

The interface labels use English. Social icons are displayed in gray over the dark homepage background.

## University emblem

`fudan.svg` is the Fudan University circular emblem, downloaded from [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Fudan_University_Logo.svg). The file credits Fudan University for the original emblem and Prcmise for the vector version. The [official identity reference](https://www.fudan.edu.cn/bsxt/) was used to confirm the design. The original vector is preserved and CSS displays it in white.
